Meteor Lite (Fabric 1.21.4) - Nuker, NoRender, Block Selection
Dựa trên Meteor Client (GPL-3.0) -> mod này cũng GPL-3.0.

Phím mặc định (đổi trong Controls):
  N            bật/tắt Nuker
  B            bật/tắt NoRender
  V            bật/tắt Block Selection
  Right Shift  mở màn hình Settings

Settings lưu ở config/meteorlite.json.
Build: đẩy lên GitHub, tab Actions -> tải artifact meteor-lite.
